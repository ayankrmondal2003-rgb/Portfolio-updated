## 🌟 Overview

The main frontend application workspace for Ayan Kumar Mondal's portfolio, powered by React 19, TypeScript, Vite, GSAP, and Tailwind CSS.

---

## 🛠️ Local Development

```bash
# Install dependencies
npm ci

# Start Vite dev server on http://localhost:5173
npm run dev

# Run comprehensive verification suite (typecheck + lint + test + build)
npm run check

# Preview production build locally
npm run preview
```

---

## ⚡ Deployment on Vercel

Configured for zero-config Vite deployment on Vercel Hobby tier:
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
- **SPA Rewrites**: Handled in `vercel.json`
- **Asset Caching**: Immutable 1-year cache headers for `/assets/*`
- **Environment Variables**: None required!
